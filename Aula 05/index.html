Aula 5: Dominando o CSS

Nessa aula, refatoramos o código CSS para usar **Variáveis** (--cor-primaria) e **Unidades Relativas** (rem). Isso garante que o site seja mais flexível e responsivo.

O conceito mais importante é o **Modelo de Caixa (Box Model)**. Cada elemento HTML é uma caixa, e suas dimenções são controladas pelo **conteúdo**, **padding** (espaçamento interno), **border** (borda) e **margin** (margem externa).

Pontos Chave da Aula 5

  1. Definimos variáveis CSS no :root para cores e espaçamento.
  2. Usamos box-sizing: border-box; (o melhor amigo do desenvolvedor).
  3. Introduzimos o **Modelo de Caixa88: Conteúdo, Padding (espaço interno) e Margin (espaço externo).
  4. Migramos de 'px' para 'rem' para criar um design mais escalável.
